# Housing Price Predictor

A machine learning project that predicts California housing prices using **Python** and **Scikit-learn**.

## Features

* Preprocessed and explored housing data using **Pandas** and **NumPy**
* Trained **Linear Regression** and **Random Forest** models
* Used **5-fold cross-validation** and **GridSearchCV** for hyperparameter tuning
* Evaluated model performance using **MAE, RMSE, and R²**
* Saved the trained model using **Joblib**

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Jupyter Notebook
